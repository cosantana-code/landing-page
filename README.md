# KOMOREBI & NORD — Japandi Single-Page Landing Experience

A bespoke, responsive single-page landing site designed in the **Japandi** aesthetic—fusing the contemplative wabi-sabi philosophy of Kyoto with the warm, human-centered hygge living of Copenhagen.

## 🌿 Concept Overview
- **Brand**: *Komorebi & Nord*
- **Focus**: Mindful Architectural Sanctuaries (timber pavilions & homes) & Handcrafted Living Artifacts (washi lanterns, wood-fired ceramics, ash furniture, raw flax textiles).
- **Aesthetic Direction**: Japandi (earthy terracotta, lichen green, washi cream, raw ochre, charred cedar, shoji screen grid subtleties, generous negative space).

## ✨ Interactive Features
1. **Zen Ambient Sound Synthesizer**: Pure Web Audio API pentatonic bell / chime generator with a top-bar toggle (no external audio files needed).
2. **Shoji Scroll Depth Indicator**: A delicate terracotta progress thread tracking your journey down the single page.
3. **Interactive Living Object Inspector**: Examine details, provenance, and pricing for artisan-made home artifacts with interactive drawer views.
4. **Sensory Materiality Explorer**: Live switcher between untreated Kiso Hinoki, charred Yakisugi, Danish oiled oak, and mulberry washi paper with sensory specs.
5. **Architectural Pavilion Blueprints**: Vector elevation studies of modular sanctuaries (*The Chashitsu Pavilion*, *The Fjord Sanctuary*, *The Engawa Studio*).
6. **Mindful Dialogue Inquiry**: A slow, unhurried consultation intake form designed to evoke thoughtful reflection rather than high-pressure conversion.

## 📁 File Structure
- `index.html`: Fully self-contained, responsive single-page web app with Tailwind CSS and inline interactive JavaScript.
